# @repo/mock-data

Fake JSON data for local dev / demos across apps.

## Usage

```ts
import { users } from "@repo/mock-data";
```

Or import raw JSON directly:

```ts
import users from "@repo/mock-data/users.json";
```

## Add to an app

```json
"dependencies": {
  "@repo/mock-data": "workspace:*"
}
```
